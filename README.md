# Tab Organizer — downloads

The download page, version history and release files for **Tab Organizer**, a
Chrome extension that files your tabs into named tab groups: rules decide most
of them for free, AI handles the rest, and your groups stay in your own browser.

- **Download page:** https://alex-bisgould.github.io/tab-organizer-releases/
- **What's new:** https://alex-bisgould.github.io/tab-organizer-releases/whats-new.html
- **Privacy:** https://alex-bisgould.github.io/tab-organizer-releases/privacy.html
- **Every release:** https://github.com/alex-bisgould/tab-organizer-releases/releases

## Installing

From the Chrome Web Store when the listing is live — that copy updates itself.
Otherwise download `tab-organizer.zip` from the latest release, unzip it, open
`chrome://extensions`, turn on **Developer mode**, choose **Load unpacked** and
pick the unzipped folder. A zip install does not update itself, and Chrome
treats it as a separate extension with its own groups and rules.

## About this repo

It holds the published site and the release artifacts only. The extension's
source is kept in a private repository; these pages are generated from it, and
issues here are the place to report a problem or ask a question.
